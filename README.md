# Second-PRD
## Weekly Coding Practice Tracker
This project is a Java-based Weekly Coding Practice Tracker.
### Objective
The program tracks coding practice for seven days and calculates:
- Total problems attempted
- Total problems solved
- Total practice hours
- Success percentage
- Average problems solved per day
- Productive days
- Non-productive days
- Weekly target status
- Consistency status
